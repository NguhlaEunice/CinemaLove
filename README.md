  Android App built with  Kotlin to browse and search romance movies 
    FEATURES
    -Splash Screen and movie list
    -Movie details screen
    -Settings screen
    -Favourites
    TECH STACK
     -Kotlin
     -Android Studio,Gradle(Kotlin   DSL)
     -RecyclerView with custom adapters
     -library:Glides
     HOW TO RUN 
       -Clone the repository
       -Open it in Android Studio
       -Sync Gradle and run on an emulator
